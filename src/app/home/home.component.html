Patota · Arquitectura & Flujos
Arquitectura del Sistema

Aplicación web modular construida con HTML5 semántico, CSS3 Vanilla y lógica reactiva en JavaScript. Enfocada en ofrecer baja latencia y alta fluidez de carga en redes móviles inestables durante actividades al aire libre.

Flujo de Datos

La información de rutas y paseos se consume desde servicios de geolocalización locales y almacenamiento local (LocalStorage) en el navegador del usuario para asegurar el funcionamiento sin conexión en zonas remotas.

Kuichi Web · Ingeniería & Integración
Arquitectura de Capas

Diseño basado en una arquitectura cliente-servidor de tres capas:

  • Presentación: Single Page Application construida en Angular, estructurando componentes reactivos y vistas reutilizables.
  • Negocio (API): REST Controller desarrollado en Java con Spring Boot, gestionando autenticación mediante Spring Security y mapeo de datos con JPA/Hibernate.
  • Datos: Base de datos relacional PostgreSQL con modelado de datos para dueños, mascotas e historiales de citas.
Kuichi App · Arquitectura Híbrida
Estructura Híbrida Móvil

Aplicación construida usando Ionic Framework combinada con Angular. Capacitor actúa como puente nativo permitiendo el acceso directo a componentes del dispositivo como notificaciones y almacenamiento persistente.

Integración

Se comunica mediante HTTPS seguro con la API REST de Spring Boot para sincronizar en tiempo real el historial médico de las mascotas.
